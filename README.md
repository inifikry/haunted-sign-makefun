# Funniest Sign on a Haunted Server Room Door

One funny sign for the door of a haunted server room, written by
`main.py` to `/output/entry.txt`.

## The sign

> Do not exorcise the ghost in rack 7: he is the only one who remembers the root password.

The joke: the ghost is not the problem, he is the only sysadmin left
who still knows the root password. Exorcising him would lock everyone
out of the servers for good.

## How to run

```sh
python3 main.py
```

It writes a single line (88 characters, UTF-8) to `/output/entry.txt`.
